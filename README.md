# Portfolio Website

## Overview

This is a personal portfolio website created to showcase projects and skills. It includes sections such as About, Skills, Projects/Experience, and contact information. The site uses HTML, CSS, and a bit of JavaScript for smooth navigation.

## Features

- **Responsive Design**: The website adapts to different screen sizes using flexible CSS units like `rem` and `vh`.
- **Smooth Scrolling Navigation**: A JavaScript function allows for a smooth scroll to sections within the page.
- **Social Media Links**: Easily accessible links to various social media platforms.

## Technologies

- **HTML**: Used for structure and content.
- **CSS**: Used for styling and layout.
- **JavaScript**: Used for interactive elements (smooth scrolling).

Usage
Navigation: Click on the navigation links to jump to different sections of the portfolio.
Project Links: Click on project images in the Works section to open the respective projects in a new tab.
Customization
Profile Information: Update the ABOUT section in index.html with your personal information.
Project Links: Modify the links and images in the WORKS section to showcase your projects.
Styling: Adjust the styles in Style.css to change the look and feel of your portfolio.
